Primary navigation row for the sidebar (desktop) and menu drawer (mobile).

```jsx
<nav>
  <NavItem icon="music" label="Toques" active />
  <NavItem icon="info" label="Sobre" />
  <NavItem icon="mail" label="Contato" />
</nav>
```

- Default variant sits flush against the sidebar's left edge (square left corners, 4px bar).
- `inset` = all-round 10px corners for drawers.
- Labels are single nouns, sentence case.
